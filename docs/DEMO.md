# Roteiro de demonstração — Service

Use este roteiro na apresentação para o professor.

## Preparação

```bash
npm install
npm run dev
```

Abrir a URL do Vite. Se necessário, limpe o `localStorage` da origem para começar no preset Petshop.

## Roteiro

1. **Login** — clique em “Visualizar demonstração” (ou Entrar).  
2. **Dashboard** — mostre cards de Petshop: agendamentos, pets, vacinas, faturamento.  
3. **Agenda** — alterne Dia/Semana; aponte profissionais/serviços/status.  
4. **Clientes** — abra a ficha de Mariana; mostre bloco **Dados do Pet**.  
5. **Ficha do Pet / Vacinação** — menu lateral; destaque que é módulo opcional.  
6. **Header → Modo de Demonstração → Barbearia**  
7. Observe: nome Barber Prime, tema azul/dourado, menu sem Pet/Vacinação, dashboard com avaliações.  
8. Abra um cliente — campos de preferências da barbearia.  
9. **Módulo → Avaliações**.  
10. **Módulos** — desative Avaliações; mostre sumiço no menu; tente `/modulo` conforme flags.  
11. **Modo de Demonstração → Academia** — Planos, Frequência, pagamentos recorrentes.  
12. **Clínica de Estética** — Anamnese, labels Paciente/Especialista.  
13. **Personalização** — mude cor e label; mostre reflexão imediata na Sidebar/Header.  
14. Recarregue a página — configuração permanece (`localStorage`).

## Frase-guia

> “É o mesmo produto. O que muda é a configuração da Linha de Produto: features, regras, tema e linguagem do domínio.”
